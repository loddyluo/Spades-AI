# 含 Nil 的前 4 墩规则式策略

> **对标**:`strategy/rule_based_first4_player.py`(非 nil 版)、`strategy/rule_exact_first4_player.py`(前 4 墩规则 + 后 36 张精确求解器的混合路由)。本文档只描述策略,不含代码。

---

## 0. 总览

### 0.1 作用范围与信息模型
- **只管前 4 墩**。第 5 墩起交给 nil-aware 的精确求解器(`ExactDoubleDummyCppFastestSolver` 读 `max_bid`,nil→0 / blind_nil→14)。开局只负责**布局**,不负责算完 13 墩。
- 玩家**盲眼**:可见 = 自己 13 张手牌 + `state_view["table_cards"]`(本墩桌面)+ `card_played` 历史 + `state_view["bids"]`(所有人叫牌)+ `state_view["tricks_won"]`(每人累积墩数)。**别人具体手牌只能靠推断**(已亮空门、已出过的牌、nil 首攻花色)。

### 0.2 读 bid
- 对每个座位取**最后一个非 `pass` 的 bid**;`nil 类 = {"nil", "blind_nil"}`。
- blind_nil 在出牌阶段与 nil **完全等价**,只是分差(±100 vs ±50)。

### 0.3 角色分派(每墩判定,度量开局算一次)

| 优先级 | 条件 | 角色 |
|---|---|---|
| 1 | 我自己叫了 nil | **Nil 本人**(§2) |
| 2 | 我队友 `(pos+2)%4` 叫了 nil | **Nil 队友**(§3) |
| 3 | 某个对手叫了 nil | **Nil 对手**(§4) |
| 4 | 都不是 | 现有非 nil 策略 |

**队友优先于对手**:两队都有 nil 时各自走队友策略(保自己 nil 的 ±50/±100 优先于攻对方)。`start_game` 在 bidding 之前,度量在开局预算,角色分派在出牌阶段才能确定。

## 1. 座次几何

固定队伍 0&2 vs 1&3 ⇒ 座次永远「nil 之后隔一个才是队友」。记 nil = N,循环顺序恒为:

```
N(nil) → A(我方,nil 后) → P(nil 队友) → B(我方,nil 前) → 回到 N
```

对手座位:
- **A = King 座**:nil 在我右手,我紧跟 nil 之后出牌 → 看得到 nil 的牌(§4.6)。
- **B = Bitch 座**:nil 在我左手,我先于 nil 出牌(§4.7)。

队友座位(§3 视角):我 3rd 手时领出者 = nil(盖它自己的领出牌);我 4th 手时 nil 是第 2 个出;我 lead/2nd 手时 nil 还没出。

## 2. 黑桃王的核心(贯通三角色的 10 条原理)

> 以下原理跨 §2 / §3 / §4 全角色复用,是写规则时必须查的硬约束。

| # | 原理 | 一句话 |
|---|---|---|
| P1 | **Nil 输是吸收态** | nil 输 1 墩即合约死,−50 / −100 锁定,不可累加。"现在确定的吸收态"永远凌驾"未来期望损失"。 |
| P2 | **三层决策结构** | 硬护栏(必删) ⊃ 铁律(必做) ⊃ 算账(优化)。先过滤后算账。 |
| P3 | **相对大小压过绝对大小** | 牌的强弱用 `lo(C) = unseen 里比 C 小的张数`,不看绝对 rank。`lo` 大 = 大牌 / `lo` 小 = 小牌 / `hi=0` = boss。`lo` 随历史翻转。 |
| P4 | **资源 = 深度** | 一门的"强度" = 能反复使用的次数,不是顶牌多大。`A 单顶 ≠ 强`,`KQJ ≥ A2`。 |
| P5 | **门槛由我顶** | 桌面赢家牌是连续可改写的"门槛";后手只能抬不能压。nil 末家 ≠ nil 安全。Coverer 顶高造港 / Nil 自己设低 / 对手 B 座贴 L 下方都是同原则。 |
| P6 | **动作多义性** | 好动作同时威胁多个目标,让对方两个回答都对我有利。 |
| P7 | **座次几何** | N→A→P→B 不变量决定行动可能性,先于策略。 |
| P8 | **空门是双向战略资源** | 可主动制造或阻止。Nil 推自己往空门;对手攻 nil 的最长门阻止它做空门。 |
| P9 | **将吃 = 目标耦合的不可逆动作** | 只为四类目标用:救 nil / 即杀 nil / 破黑桃 / 4th 拿明确合约墩。**无目标将吃黑桃是负价值伪行动**。 |
| P10 | **前 4 墩 = 给求解器的 handoff** | 不结算 13 墩盈亏,目标是交一个干净留足资源的局面:nil 已甩高危门 / 黑桃没破 / 队友盖牌还在 / 对手剥光 nil 小牌。 |

## 3. Nil 本人策略

**目标**:前 4 墩取 0 墩,顺手甩高危牌、做空门,给求解器交易输的局面。

### 3.1 花色危险度 `DANGER(S)`

**核心口径**:一张牌危不危险,看 `lo(C)`(它能压过几张未见牌)。比 J 大的只有 Q/K/A 三张,但 J 能压过 2~10 共 9 张 → J 是危险大牌,不是小牌。

**原子量**(纯盲眼,随历史更新)。设 `unseen(S)` = S 里既不在我手、也没在历史出现过的牌:
- `lo(C)` = `unseen` 里比 C 小的张数 = C 被迫打出时能压过的牌数。**`lo` 越大越危险**。
- `hi(C)` = `unseen` 里比 C 大的张数;`hi(C) = 0` ⇒ **boss**(必赢,危险拉满)。

**关键安全谓词**(非对称双阈值,§5.1 待定阈值):
- `safe_low(C)` := `lo(C) ≤ 2~3`(几乎压不过谁)— 判定最小牌/护盾是否安全。
- `safe_second(C)` := `lo(C) ≤ 5~6` — 放宽,判定次小牌是否安全。
- `escapes(S)` = 我在这门里满足 `safe_low` 的张数(逃生弹药)。需要第 2 张才算真有逃生力。

**将吃折扣 `cover(S)`** —— `outstanding(S) = 13 − 我张数 − 已出现张数`(还在别人手里的)。我越长 → `outstanding` 越小 → 大牌越可能被将吃 → 越安全。**`outstanding` 越小越降档,单调**。

**分档**(高→低):

| 档 | 触发(折扣前) |
|---|---|
| **T5 极危** | 有 boss(`hi=0`)且 `escapes = 0` |
| **T4 高危** | 有 boss 或高 `lo` 危险牌,`escapes = 1` |
| **T3 中危** | 有危险牌,`escapes ≥ 2` |
| **T2 低危** | 我最高的牌 `lo` 也不大(全相对低牌) |
| **T1 安全** | 全极低牌 / 短门全 `lo ≈ 0` |
| — | 空门:无危险度 |

**将吃折扣降档**(叠在分档之上,黑桃不享):

| 触发 | 降档 |
|---|---|
| 观测到队友硬 void | 直接砍到 T1 |
| `outstanding ≤ 1`(我几乎独占) | 降 2 档 |
| `outstanding = 2` | 降 1 档 |
| `outstanding ≥ 3` | 不降 |

**比较键** = `(tier, max lo 值, 长度)` 字典序。**同档黑桃算最危险**(spades-last,垫牌优先甩非黑桃)。

### 3.2 核心谓词 `is_guaranteed_loser(C | 桌面)`

C 是保证输的牌 ⟺ 当前赢家牌 W 压过 C(`not beats(C, W, lead_suit)`)。
**定理**:已在桌上、已压过 C 的牌,后手只会让赢家更大,永不会反过来。所以"W 压过 C" 精确 = "C 这墩不可能赢"。空门时打的任何非黑桃牌恒为保证输。

### 3.3 首攻(选门 + 选牌)

只在合法可领花色里选(黑桃未破不能领黑桃,除非满手黑桃)。按桶取第一个非空桶:

1. **桶 1 安全单张**:单张且该牌满足 `safe_low` → 取其中 `lo` 最小那门。
2. **桶 2 安全双张**:双张且高张满足 `safe_low` → 取高张 `lo` 最小那门,**领高张**(清掉较大那张,留单张下一步成空门)。
3. **桶 3 最不危险长门**(≥3 张):取 `DANGER` 最小那门,**领第二小的牌**(留最小作自保 duck);该第二小应满足 `safe_second`,否则视该门不合格,退到 `DANGER` 次小的门。黑桃则领最小黑桃。
4. **桶 4 兜底**:无安全候选时,从可领集合去 boss 牌(若还剩),出 `lo` 最小那张;若全 boss,出全局 `lo` 最小。

**硬护栏**:任何会赢的短门高牌(单张 boss、A-x / K-x 双张里高张是 boss)**不进桶 1/2**,留着以后 duck/垫。

### 3.4 跟牌(手里有领花)

取手里领花中所有保证输的牌:
- **非空** → 出其中**最大**那张(零风险甩最大安全牌)。
- **全压过当前赢家**(无安全输牌):
  - **非末家(2nd/3rd)** → 出最小(后面还有人,最可能被盖)。
  - **末家(4th,必赢)** → **切换到吃墩模式**:nil 这墩已爆,不再为这墩做 nil 规避,按普通吃墩逻辑出**最小赢张**。

### 3.5 空门(将吃 or 垫牌)— 永不取胜

**铁律**:手里有非黑桃就一律垫,绝不将吃(将吃必压非将 = 立刻赢 = nil 爆)。

**垫牌优先级**(`DANGER` 最大门的最大牌,具体语义):
1. **不可避免的赢张**最先甩:裸 boss、缺低牌保护的 boss(单张 A/K、`lo` 高且 `escapes = 0`)。
2. **没有低牌缓冲的中间牌**其次:裸 10 / 9 这类(中 `lo`、`escapes = 0`,教程称"隐形杀手")。
3. **长套里的高牌**最后:被将吃折扣压低、几乎轮不到被逼出的牌。

**关键安全约束**:垫牌**只在非黑桃花色里选**——非黑桃领出的墩里打黑桃就是将吃必赢,直接爆 nil。高黑桃只能跟黑桃领出且其下已有更大黑桃时出,否则留给求解器。低黑桃优先于高黑桃保留。

**满手只剩黑桃被迫出将**:按 §3.4 「保证输」口径在黑桃间处理。

## 4. Nil 队友策略

**两件事**:① 绝不让 nil 的牌赢;② 兜住本队数字合约且不超墩。

### 4.1 花色防守实力 `DEF_STRENGTH(S)`

**核心**:Coverer 的实力 = **能盖几次 = "不小的牌"的张数(深度)**。失败模式是被剥到只剩一张小牌可出 — 对手齐压低,nil 跟这门无低牌可垫,被迫赢。所以要的是**深度**,不是顶牌。

- **"不小的牌"** = `lo(C)` 够大(具备盖低位领出的能力);`lo` 极小、谁都压不过的牌算"小牌",盖不了任何东西(§5.1 阈值)。
- **非黑桃** `DEF_STRENGTH(S) = 该门"不小的牌"的张数`。例:`KQJ = 3`(强),`Axxx = 1`(弱,A 一走该门塌成小牌),`Qx = 1`,`Jxxxx ≈ 1`。**A 单顶 ≠ 强**。
- **黑桃** `DEF_STRENGTH = 黑桃张数`(每张都能将吃通杀任何旁花)。

**分类**(驱动"该花 vs 该省"):

| 类 | 触发 | 用法 |
|---|---|---|
| **STRONG** | `DEF_STRENGTH ≥ 2`;或黑桃 ≥ 2 | 用够用最便宜赢张,盖完仍有后手 |
| **FRAGILE** | `= 1`(`Axxx`、裸 K、`Qx`、孤 Q、单张黑桃) | 唯一盖牌,只为必须盖 nil 才花 |
| **LOW** | `= 0`(全小牌) | 盖不了任何东西,危险门 |

### 4.2 合约追踪 `tricks_needed`(每墩重算)

`tricks_needed = 我的数字叫牌 N − (历史里赢家是我或 nil 的已完成墩数)`。

- `ACQUIRE`(还要墩):可用够用最便宜赢张拿墩。
- `PROTECT-ONLY`(合约已够):一墩都不多拿,duck 第一(每超 −9)。

### 4.3 优先级

1. **盖 nil(凌驾一切,含超墩)**:nil 当前赢家且我能盖 → 执行盖牌程序。
2. **布局**(nil 未出,我 lead/2nd):走对应 recipe。
3. **拿合约**(`ACQUIRE` 且 nil 已安全):便宜赢就赢。
4. **保深度**(`PROTECT-ONLY` 且 nil 已安全):出最小、保盖牌深度(尤其脆门唯一盖牌和黑桃)。

**盖牌程序**:有领花 → 出能压过当前赢家的最小领花牌(压不过出最小,接受 nil 赢);空门 → 用能压过的最小黑桃将吃。选牌键:先非黑桃、再 rank 最小、够用即可。

### 4.4 首攻(我赢得领牌权,本墩 nil 第 3 个出)

**默认「领高造避风港」**:在桌面筑高牌屏障让 nil 把危险中高牌(Q/J/10)垫在下面。保 nil 的 ±50/±100 凌驾 −9,**不仅 `ACQUIRE` 才做**。

按下列顺序取第一个适用:
1. **已知 nil 某旁花空门** 领这门花色最大张
2. **最高 `DEF_STRENGTH`(最深)那门里我能赢墩的高牌**(造港 + 掌控 + 保深度)。例:`A K x` → 领 **A**(留 K 续盖)。**脆门(深度 1,如 `A 2`)只在没有更深门时才用**——领高会一次性烧光唯一盖牌。
3. **优先领"我最强、推测 nil 最弱/最短"的花色**:消耗对手防守资源,加速 nil 在该门空门。

**禁忌**:
- nil 还活着时不主动领黑桃(除非已知 nil 黑桃空门、或只剩黑桃合法)。
- **绝不向已知对手空门的花色领出**(除非该门对手与 nil 同时空门)— 对手轻松将吃夺领牌权。
- 即便 `PROTECT-ONLY`,也不为省 −9 而把领牌权送出 — 对手拿到领牌权就会攻 nil。

### 4.5 2nd 手(对手领出,本座 nil 最后出)

**核心**:按领出牌高低决定是否抬门槛,给 nil 造一个能 duck 进去的避风港。**「nil 最后出能自保」是错的**——它只能 duck 到 ≤ 当前赢家;门槛低时它可能全部更大 → 被迫赢。

**有领花**:
- **领出牌偏低(门槛低,nil 危险)→ 出大**:打够高的盖牌顶起门槛造港。**唯一盖牌也要用**(留着不用 = 0 防守)。能造港的前提下选较便宜的(如 `A K x`、对手领 3 → 出 K 留 A)。
- **领出牌偏高(门槛已够 nil 躲)→ 出小**:保盖牌深度,顺手清自己低牌。
- 该门 LOW(无盖牌)→ 造不了港,出该门最高的小牌(聊胜于无)。

**空门**:
- **领出牌偏低 → 将吃造港**:用最小够用黑桃将吃,把门槛顶到将牌级。除非已知 nil 在领花也空门(那 nil 自己垫掉即可)。
- **领出牌偏高 → 垫**:垫我 `DEF_STRENGTH` 最弱门的牌,保住强门深度。

### 4.6 3rd 手(领出者就是 nil,我后面只剩 1 个对手)

**铁律**:`is_nil_winning = True` 且我能盖,**就盖,无条件,不算深度账**。nil 输 1 墩即死的吸收态远超"未来同门又被攻"的条件式期望。**深度账只对 `is_nil_winning = False` 生效**。

- **`is_nil_winning = True`**:
  - 领花有更大牌 → 用最便宜压张盖,**包括脆门唯一 honor**(例:nil 领 ♥9、2nd 出 ♥4、我 `♥A ♥3` → 必须用 ♥A)。
  - 领花无更大、空门有将 → 用最小够用黑桃将吃,**包括单张黑桃也将**。
  - 盖不过 → 出最小,接受 nil 赢、合约爆。
- **`is_nil_winning = False`**(已有对手盖过 nil):
  - `ACQUIRE`:只用 STRONG 门最便宜赢张拿(4th 还能反超,**绝不投机花脆 honor**);否则出最小。
  - `PROTECT-ONLY`:出最小领花(空门垫最弱门)。

### 4.7 4th 手(nil 第 2 个出,我末家全信息)

铁律分两层:
- **`is_nil_winning = True`**:同 §4.6,能盖就盖、无条件,脆 honor 也花,单张黑桃也将吃。
- **`is_nil_winning = False`**:「末家盖必生效」≠「末家盖必划算」,**深度账重新生效**:
  - `ACQUIRE` + 该门 STRONG → 用最便宜压张拿合约墩。
  - `ACQUIRE` + 该门脆 → **不花脆 honor 拿合约墩,出最小**。这张 honor 的"未来护 nil"期望价值远超 +10 合约墩。
  - `PROTECT-ONLY` → 出最小。

### 4.8 空门且非盖牌情形

垫最小非黑桃、留全部黑桃(将牌专留救 nil 和后段合约)。只在「盖 nil」或「4th 手拿明确需要的合约墩」时才将吃,且永远用最小黑桃。

## 5. Nil 对手策略

**三目标**(有序优先):
- **A. 宕 nil**(±50 / ±100,吸收态)
- **B. 完成自己这队数字合约**
- **C. 宕 nil 队友数字合约**

**不算"避免给对方造 −9 超墩"**(前 4 墩不值)。

**架构**(P2 三层):**硬护栏(§5.2)⊃ 铁律(§5.5–5.7 各分支)⊃ 算账(`ATTACK` + 重心)**。

### 5.1 `bid_sum` 全局重心

`bid_sum` = 四家叫牌数字之和(nil/blind_nil 计 0)。**所有非铁律的算账都被它偏置**:

| `bid_sum` | 重心 | 含义 |
|---|---|---|
| **≤ 10** | 偏宕 nil(A) | 牌局松,火力集中攻 nil(剥小牌、续攻、贴 L) |
| **11** | 居中 | 两目标兼顾 |
| **≥ 12** | 偏宕 Coverer(C) | 牌局拥挤,Coverer 合约易死;多目标试探常态化(§5.9) |

**铁律凌驾**:**零代价宕 nil 无视 `bid_sum`**。nil 自己当前正赢、我能不付任何代价让它继续赢 → 永远做(典例:nil 拿 ♥9 ♥2 出 ♥9、2nd 出 ♥4,我 King 座 `♥A ♥3` → 出 ♥3 让 ♥9 当赢家)。

### 5.2 硬护栏(必删动作)

下列动作**从候选池删除,不进任何后续算账**:

1. **绝不盖正在赢的 nil**(同花更大牌 / 任何将吃)— 救 nil = 翻吸收态 = 送 −50。
2. **绝不无目标将吃黑桃**(领花是黑桃时):"最小黑桃将吃黑桃"是零攻击力伪行动,只烧深度。
3. **绝不向 nil 已知空门(`nil_void(S) = True`)的花色领出** — 给 nil 免费垫高危。
4. **绝不向 nil 已主动领过的花色再攻** — 那是它最安全/最长的门。
5. **nil 还在赢、我能多压时绝不用最大领花抢墩** — 多花高牌只是给 nil 续命。
6. **nil 还活着时绝不主动破黑桃**(除非空门 + 本墩下不了套 + nil 黑桃未 void,见 §5.8)。

### 5.3 推断量

- **`nil_void(S)`**:某门 S 被领出时 nil 没跟 → 确定空门。**nil 只是"领"某门不算空门**(多半它的安全单张/双张高)。
- **`nil_led_suits`**:nil 作为领出者开过的花色。
- **`nil_inferred_lowest(S) = L`**:S 里**当前未出现**(未在我手 ∪ 历史 ∪ 桌面)的最小 rank。L 是"nil 在该门被迫跟出的牌"的严格下界(它 duck 时给最小,≥ L)。仅下界,故 §5.7 ①「贴 L 下方」。
- **`outstanding(S)` / nil 该门估计长度** = `13 − 我手张数 − 已出现张数`,均摊三家就是 nil 该门期望长度。

### 5.4 花色攻击力 `ATTACK(S)`(开局算一次,可随历史轻刷新)

**完全用 `lo` 刻度**。提醒:**`lo` 大 = 大牌;`lo` 小 = 小牌**。攻方弹药是 `lo` 小的牌(领出几乎必输、把门槛压到地板)。

三个因子:
1. **小牌深度** `depth_low(S) = 我手里 lo(C) ≤ 2 的张数`(地板攻次数)。
2. **nil 该门预估长度** = `outstanding(S) / 3`(若 `nil_void` 则 0)。
3. **自救负担** `my_burden(S) = 我手里 lo(C) ≥ 7 的非 boss 张数`(中段或更高,领出会自己赢救 nil)。双刃:`ATTACK` 里轻负,§5.9 多义试探里转武器。

```
ATTACK(S) = 2·depth_low + 1·nil_estimated_length − 0.5·my_burden
          + 续攻锚加分(上次攻击的门、nil 未 void、depth_low ≥ 1)
```

**黑桃单独**(不进旁花排名):攻黑桃仅当(黑桃已破 ∨ 我能破)∧ `not nil_void(SPADES)` ∧ 我有 `lo ≤ 2` 的低黑桃。否则黑桃 `ATTACK = −∞`。

### 5.5 首攻(攻击)

**选门**:通过 §5.2 硬护栏过滤,在剩余合法花色取 `ATTACK` 最高那门;**续攻偏好**:上次攻击的门仍合格且 `depth_low ≥ 1` → 优先续攻。

**选牌**(用户骨架 B「多义试探」的核心舞台):
- **默认**(`bid_sum ≤ 11`)**:领该门 `lo` 最小那张**(把门槛压到地板)。
- **`bid_sum ≥ 12`:启用多义试探**:领该门**中等 `lo`** 的牌(`lo` ≈ 5~8,非 boss 也非地板)。
  - 对 nil:门槛偏低仍可能逼它顶上(A 部分保留)。
  - 对 Coverer:中等门槛**强迫二选一**——盖吃就废 honor/烧黑桃(C 加分),让墩则我方稳拿(B 加分)。同时威胁 A + B + C。
- **永不领该门 boss**(P10 + 硬护栏 5)。

**King 座专属杀招**:若读出 nil 残局只剩黑桃,直接领极低黑桃强制右侧 nil 赢墩(Coverer 坐第一位、无预知)。前 4 墩此条件罕见,真出现则极高优先。

### 5.6 King 座跟牌(nil 已出,我紧跟)

按 `is_nil_winning(table)` 二分:

**A. nil 当前是赢家**(目标 = 维持):
- 有领花:出 `lo` 最大且仍 < nil 的领花(顶门槛只需够用 + 顺手甩高隐患)。
- 领花全 > nil(被迫盖)→ 出领花最大(切吃墩模式 + 抢领牌权,不喂给坐我后面的 P)。
- 空门 → 出最大非黑桃(必输给 nil 的领花,nil 继续赢,顺手甩隐患);**绝不将吃**。

**B. nil 不是赢家**(已被 Coverer / 自己出大牌摔了):核心判据是 `small_depth(S)`(下方动态阈值),不是"盖谁"的礼仪。

> **小牌的动态定义**(P3 精确化,阈值随 unseen 缩小而收紧):
> ```
> small_threshold(S) = floor( unseen(S) / 3 )
> small(C, S)        = lo(C) ≤ small_threshold(S)
> small_depth(S)     = 我手里这门满足 small 的张数(排除将出的那张)
> ```
> 开局 unseen ≈ 9~12 → 阈值 3~4(底层 4~5 张算小);末段 unseen = 1 → 阈值 0(仅 `lo = 0` 算小,`lo = 1` 在 unseen = 1 时是 boss)。

设 `top_in_suit` = 我领花最大牌、`W` = 当前赢家:

- **`top_in_suit ≤ W`(盖不过)** → 出最大非黑桃(扔最大 burden;搭档赢仍 +10,对方赢至少清 burden)。
- **`top_in_suit > W` + 赢家是搭档**:
  - `small_depth ≥ 2` → **不盖**,出**领花里 ≤ W 的最大牌**(同 §3.4 nil「保证输牌里最大」、§5.7 ①「< L 最大」的同形落点 — 在"不反超"约束下顺手扔最大 burden;搭档 +10 已稳)。
  - `small_depth ≤ 1` → **盖**,出最大非黑桃。不盖也救不了未来 — 剩下全 burden,以后必爆;不如现在在安全墩里清掉最大 burden,顺手抢领牌权。
- **`top_in_suit > W` + 赢家是对手**(Coverer / nil 队友) → **几乎总盖**,出最大非黑桃(抢 +10 + 清 burden + 抢领牌权,三重收益)。
- **空门** → 几乎总不将吃(此处赢家非 nil,将吃无目标);垫最大非黑桃。例外:`bid_sum ≥ 12` + 合约缺墩 + 干净拿稳得 → 用最便宜黑桃将吃。

### 5.7 Bitch 座跟牌 / 领出(我先于 nil)

**关键二分**:`P_already_played`(P 本墩出过没有?)

**情形 ① P 已出过(领出者是 A 或 P)→ 干净下套**:设 `L = nil_inferred_lowest(领花)`、`W = 当前赢家`。
- **下套不可能 → 走 §5.8 保存/甩牌**:`nil_void(领花)`、或 W 是将牌而领花非黑桃(nil 跟旁花躲不过将,自动 duck)、或 W 是领花牌但 `rank ≥ L`(门槛已抬过 nil 最低牌)。有领花出最小,空门垫。
- **W 是领花牌且 `rank < L`,nil 正被逼** → 出 `rank < L` 中我最大的领花牌(贴 L 下方,缩 W—L 窗口又不开逃生门)。
- **我全 ≥ L** → 被迫抬门槛 ≥ L,出最小领花(无奈)。

> 「等大 > 小于 > 更大」:贴 L 正下方陷阱最紧、对 L 被低估最稳健;更深小牌只在没有更接近 L 的牌时用;跨到 ≥ L = 开逃生门、最后手段。
> 实战提醒:前 4 墩 `L` 通常较小,W < L 罕见 → 情形 ① 干净下套是稀有事件。

**情形 ② 我领出 / P 未出 → 即杀失败,转多目标试探**:P 坐我后面会救 nil。所有动作必须**多义**:
- **底线施压**:领出/跟出中 `lo` 牌(`lo` 5~8、非 boss),让 Coverer 在「盖吃废 honor/将牌」与「让墩、我方拿」间二选一,nil 为自保也会躲这档牌。
- **递信号给搭档**:赢得领牌权后切换花色领出 = 告诉 King 座搭档"上方向撞墙了,请重组"。
- **不白吃墩躲 −9**:跟牌时若注定我赢且本墩拿不到目标 → 仍出最小,避免白吃。
- **守硬护栏**:不盖 nil、不无目标将吃黑桃。

### 5.8 空门处理(统一)

- **本墩还能下套**(nil 未出 + 情形 ① 适用)→ 不破黑桃,垫低牌保陷阱(留黑桃作后续盖资源)。
- **不能下套 + 黑桃未破 + `not nil_void(SPADES)` + `bid_sum ≤ 11`** → **用 `lo` 最大的低黑桃破黑桃**(P9 目标:解锁后续黑桃攻)。**不是最小黑桃** — 最小黑桃是宝贵盖牌资源,破黑桃是用"最能赢这墩的低黑桃"(`lo` 高的低黑桃)。
- **不能下套 + `bid_sum ≥ 12`** → 垫我最弱门(`DEF` 类比)的最大牌:消耗 Coverer 盖牌深度(攻 C 间接动作),不浪费黑桃。
- **黑桃已破 / `nil_void(SPADES)`** → 永不破黑桃;按 ≤ 11 / ≥ 12 走垫牌分支。

### 5.9 攻 Coverer 合约的辅助手段(仅 `bid_sum ≥ 12` 启用)

C 优先级升至与 A 同档(零代价宕 nil 仍凌驾)。三种附加打法:
1. **中高牌冻结**(频繁领 `lo` 5~9 的牌):同 §5.7 情形 ② 但常态化。
2. **榨干 Coverer 将牌**:故意领向已知 Coverer 空门(且**不是 nil 空门**,否则违 §5.2 硬护栏 3)— 逼 Coverer 透支高黑桃救 nil。
3. **双重缺门暴击**:Coverer 和我搭档同时空门 → 领该门,Coverer 必将吃,我搭档可超将吃(消耗 Coverer 将牌 + 我方 +10)。前 4 墩极罕见。

`bid_sum ≤ 11` 时这三种**不启用**(过度纠结 C 反而稀释攻 nil 火力)。

## 6. 全角色共享机制

### 6.1 黑桃未破
只限制「领」。Nil / 队友乐于让黑桃关着(不被迫跟将、不被将攻);对手想破黑桃解锁攻击(§5.8)。

### 6.2 死 nil 回退
每墩读 `state_view["tricks_won"][nil座]`。目标 nil 已赢 ≥ 1 墩(合约死、−50/−100 锁定):
- 爆掉的 **Nil 本人** → 切非 nil 策略,转帮队友数字合约。
- **Nil 队友** → 撤掉「盖 nil」,只跑纯合约/避超墩。
- **Nil 对手** → 停止下套,回退非 nil 策略;双 nil 局则改打另一个还活着的敌方 nil。

### 6.3 多 nil 局
- **两个敌方对手都叫 nil**:每墩按本墩处境挑目标(谁正赢/最危险打谁);都没出牌时偏向打"坐在出牌对手之后的那个 nil"(它后面无人救)。
- **两队都有 nil**:每个 nil 的队友走队友策略;打对方 nil 仅作平局 tie-break。
- **同队两人都叫 nil**:都走 Nil 本人策略,互不相救(救会爆自己 nil)。

### 6.4 第 5 墩交接
`tricks_played ≥ 4` → 交给 nil-aware 求解器。全程保持 `card_played` 跟踪让求解器继承正确 void/seen 状态。**开局目标 = 交一个干净留足资源的局面**:nil 已甩高危门(最好做出空门)、黑桃没破;队友赢张/将牌基本还在(只花过够用最便宜赢张);对手剥光 nil 小牌(最好破了黑桃)。

### 6.5 acquire 节奏(保守口径)
队友前 4 墩**不贪墩**:只在「这墩本来就是盖 nil」或「零风险便宜赢」时拿,否则保存控制力,让求解器补合约。

### 6.6 Coverer 信号/记账增强(低优先)
- **逆向信号**:nil 垫 8 ⇒ 它该门最大牌 ≤ 7 ⇒ Coverer 之后可放心领 > 7 的牌。
- **安全时甩最低牌**:对手已盖过 nil 时,Coverer 趁机扔该门最小牌,保持手牌"高",避免残局被迫领低害死 nil。
